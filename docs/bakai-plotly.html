Bakai · Plotly 3D prototype

Axes: Impact, Ease, Independence. Octant volumes are intentionally very transparent, with stronger edges, so the issue points remain readable.

Bit order: Impact / Ease / Independence
Top→bottom trigram: Impact / Ease / Independence
Ease = 11 − Cost
Independent = no unresolved prerequisites

Point semantics
Circle
Issue with no downstream issues unlocked.
Diamond
Issue that unlocks one or more downstream issues.
Marker size
Bigger marker = greater Unlocking Power.
Interpretation note. An issue in Air · Hollow Fixes can still deserve early attention if it unlocks important downstream work. Bakai classifies issues, but execution order still depends on the dependency graph.
