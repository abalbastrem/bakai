Point semantics
Orb
Direct value. An issue with no downstream issues to unlock; its bright marker has a fixed size.
Gem
Direct and enabling value. An issue that unlocks one or more downstream issues.
Gem size
Larger gems indicate greater Unlocking Power, not necessarily higher priority.
Unlocking Power

The sum of the Impact scores of all distinct downstream issues, directly or indirectly dependent on this issue. Each issue is counted once, even if reachable through multiple paths. It measures potential downstream value, not guaranteed immediate unblocking.

Dependency Burden

The sum of the Cost scores (11 − Ease) of all distinct unresolved prerequisites, direct and indirect. Zero means independent. The lower half of the vertical axis uses a logarithmic scale: greater burden means greater depth. This estimates cumulative prerequisite effort, not elapsed time.

Interpretation note. An issue in Fog · Hidden Potential can still deserve early attention if it unlocks important downstream work. Bakai classifies issues, but execution order still depends on the dependency graph.
